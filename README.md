# Forma · אתר לזיהוי רהיטים

אתר שבו משתמש מעלה תמונה של רהיט, מודל CNN מזהה לאיזו מתוך 11 קטגוריות הרהיט שייך, והאתר מציג מוצרים דומים מאותה קטגוריה.

## מבנה הפרויקט

| קובץ | תפקיד |
|---|---|
| `backend/main.py` | שרת FastAPI: זיהוי קטגוריה (CNN) וחיפוש מוצרים דומים (CLIP) |
| `frontend/index.html`, `style.css`, `app.js` | ממשק המשתמש (עברית, מותאם למחשב ולטלפון) |
| `furniture_cnn_model_3.keras` | מודל ה-CNN המאומן |
| `run_server.bat` | הפעלת השרת מקומית (http://127.0.0.1:8000) |
| `run_public.bat` | הפעלת השרת + מנהרת ngrok לכתובת ציבורית |
| `requirements.txt` | ספריות Python נדרשות |

## איך זה עובד

1. **זיהוי קטגוריה:** התמונה מוקטנת ל-224×224 ונשלחת למודל ה-CNN. המודל מחזיר הסתברות לכל אחת מ-11 הקטגוריות. המשתמש רואה את כל האחוזים ויכול לבחור קטגוריה אחרת ידנית.
2. **שמירה ואישור:** בלחיצה על "שמור תמונה ואשר קטגוריה" התמונה נשמרת במחשב השרת בתיקייה `user_uploads\<קטגוריה>\`, ונרשמת שורה בקובץ `user_uploads\log.csv` (תאריך, הקטגוריה שנבחרה, הצעת המודל, ודאות המודל, האם נבחרה ידנית). התמונה נשמרת ללא מטא-דאטה (למשל מיקום GPS). אם המשתמש משנה קטגוריה ושומר שוב, התמונה מועברת לקטגוריה החדשה ולא משוכפלת. התמונות השמורות יכולות לשמש בהמשך לאימון נוסף של המודל.
3. **מוצרים דומים:** מודל CLIP (ViT-B-16, laion2b) הופך כל תמונה לווקטור של 512 מספרים. וקטורי כל תמונות הקטלוג מחושבים פעם אחת ונשמרים. בחיפוש, התמונה שהועלתה מושווית (דמיון קוסינוס) רק לתמונות מהקטגוריה שאושרה, ומוצגים 12 המוצרים הדומים ביותר, מוצר אחד לכל דגם.

## מבנה מודל ה-CNN

Rescaling(1/255) ← אוגמנטציה (Flip, Zoom 0.2, Rotation 0.05, Translation 0.1) ← 5 שכבות Conv2D (32/64/128/256/512, 3×3, ReLU) עם MaxPooling ← GlobalAveragePooling2D ← Dense(256, ReLU) ← Dropout(0.2) ← Dense(11, Softmax).
אופטימיזציה: Adam, categorical_crossentropy, 30 epochs.

**ביצועים על סט הבדיקה (1,546 תמונות):** דיוק 69.5%; התשובה הנכונה בין 3 הראשונות ב-89.8% מהמקרים.

## קטגוריות

הדומים, כורסאות, כיסאות, מזנונים, מיטות זוגיות, מיטות ילדים, ספות, פינות אוכל, שולחנות סלון, שידות איפור, שידות לילה.

## הרצה

```
pip install -r requirements.txt
run_server.bat
```
ואז פותחים בדפדפן http://127.0.0.1:8000

## מאגר התמונות (Database)

קטלוג התמונות (כ-7,700 תמונות) אינו כלול בהגשה בגלל גודלו, והוא זמין להורדה כאן:

[הורדת מאגר התמונות מ-Google Drive](https://drive.google.com/file/d/1JGn7OEATWmDgRRq4kDz534AriASyJ8to/view?usp=drive_link)

כדי להפעיל את החיפוש של מוצרים דומים:
1. מורידים ומחלצים את הקובץ.
2. בראש `backend/main.py` מעדכנים את `DATASET` לנתיב של התיקייה `CNN_furniture_dataset` שחולצה.
3. מפעילים את השרת. בהפעלה הראשונה נבנה מאגר וקטורי ה-CLIP (כ-20 דקות, פעם אחת בלבד).

ללא מאגר התמונות, זיהוי הקטגוריה ושמירת התמונות עובדים, אך החיפוש של מוצרים דומים לא.
